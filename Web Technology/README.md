# Medical Website

## Introduction

Websites are essential tools for presenting ideas and connecting with a broad audience. This project focuses on designing a website centered around the theme of Medicine, which is particularly intriguing due to its relevance to the human body and its functions.

## Project Scope
This project includes:

HTML Files: index.html, pathology.html, radiology.html, cardiology.html, anatomy.html, and contact.html

CSS Files in the "CSS" folder: styles.css, pathology.css, radiology.css, cardiology.css, and anatomy.css

JavaScript Files in the "JavaScript" folder: pathology.js, radiology.js, and cardiology.js

Images: 40 images in the "IMAGES" folder

All files and folders are organized within the directory titled "Web Technology"

Each HTML file is interconnected through a horizontal navigation bar (navbar) styled using internal CSS from styles.css, which is linked to all pages. Additionally, each page includes internal CSS for formatting and is designed to be responsive across different devices where necessary.

## Detailed Pages
All the pages are being validated by HTML/CSS Validator

### INDEX
The index.html page serves as the website's homepage, providing an introduction to the project with a title and brief description. It features three boxes with buttons (href = "#"). Internal CSS handles the formatting.

### pATHOLOGY
Focuses on Pathology. Users see a title and a "Learn more" button, which directs them to the main section of the page. It includes an introduction, a pathologist's definition, and two additional buttons:

The first button leads to "Types of Pathology," featuring two tables (5x2 and 4x4) with type titles, brief descriptions, and images.

The second button directs users to a Mini Pathology Quiz with 10 multiple-choice questions based on the table texts. Users submit answers and see their scores. JavaScript functionality is implemented in pathology.js, and formatting is handled in pathology.css.

### RADIOLOGY
Focuses on Radiology, containing a title, introductory paragraph about its significance in Medicine, and different types of radiological imaging.
It includes an Image Gallery where clicking on an image displays a description with an option to close it. The Case Gallery features real cases with links for further study. Formatting is managed through radiology.css, and interactivity via radiology.js.

### CARDIOLOGY
It centers on the human heart. Users see a title and a central heart image with pulse effects. Buttons on the right display parts of the heart—clicking reveals brief descriptions, and clicking again hides them. This functionality is handled in cardiology.js. Further down, descriptions and heart function are detailed in two sections. Formatting is managed via cardiology.css.

### ANATOMY
It presents various anatomies of the human body. Initially, it includes a title, central body image, and a quote by Hippocrates. There are 4 sections:
- Introduction to Anatomy
- Pregnancy trimesters with buttons for each trimester (and relevant video/image), formatted using nested lists. Text structured based on NHS months and BabyCenter text.
- Human brain with an image and description

Images of the arm, leg, and stomach with links for further study. Button functionality is based on pathology.js, and formatting is managed through anatomy.css.

### CONTACT
It includes a title, contact form for users, and contact details. Formatting is handled via internal CSS.

## Conclusion
This project presents fundamental medical topics with functionality, using JavaScript for effective design. The project was created to present a medical theme with a professional yet user-friendly approach. At certain points, the text has been rephrased by me for clarity and conciseness.
